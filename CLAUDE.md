# Git rules

- Never push to any git remote. This applies to every repo this project touches.
- Never commit, amend, rebase, reset, cherry-pick, revert, tag, or otherwise rewrite git history without the user explicitly asking for that exact action.
- Leave all git operations (commit, push, history changes) to the user. Make file edits in the working tree and report what changed instead.

# Code changing rules

- Whenever you make code changes, give a quick summary with snippets of what you changed
